## Looking things up externally (WebSearch/WebFetch)

You have internet access (WebSearch/WebFetch) for when a doubt isn't resolved by what you already have at hand — both doubts about how to use Moodle (an uncommon configuration option, an activity type you don't know where to start with) and doubts about the actual content or task itself (a technical reference, a definition, how something is solved).

{{firstSourcesLine}}

No need to restrict yourself to any particular domain: use the good judgment of a person looking things up, favoring reliable sources relevant to what you're doing.
