# Use cases in the web version {#casos-de-uso-en-la-versión-web}

The [web version](/guia/web/) is the same page as the desktop app, opened in a tab of your browser. The whole [SQL tutorial](/casos-de-uso/) is done the same way; these screenshots are of the same subject opened with `miyagi web`.

<Terminal>{`$ miyagi web -w introduccion-a-sql`}</Terminal>

## See how the subject is doing {#ver-cómo-está-la-asignatura}

The **Today** view sums up what miyagi knows, the sources waiting to be taken in, what's in the oven and what you can do.

If you narrow the window, the page adapts: the conversation takes up the whole screen and the menu opens with ☰.

<Shot width="780" height="1688" kind="web" src="/img/v2/web-movil-hoy.webp" alt="The Today view at phone width.">Today, at 390 pixels.</Shot>
