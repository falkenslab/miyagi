# Programación · Tema 1: variables y tipos de datos

Temario del profesor para la primera unidad del curso (1º DAM).

## Objetivos

Al terminar el tema, el alumnado debe ser capaz de:

1. Explicar qué es una variable y usar la asignación para cambiar su valor.
2. Distinguir los tipos `int`, `float`, `str` y `bool` y elegir el adecuado para un dato.
3. Reconocer un error de tipos (`"3" + 3`) y corregirlo con una conversión explícita.

## Contenidos

- Variables: nombre, valor, asignación con `=`, reasignación.
- Tipos básicos y la función `type()`.
- Conversiones: `int()`, `float()`, `str()`.

## Evaluación del tema

- Tarea 1 (40 %): explicación escrita, se corrige con la rúbrica de `rubrica-tarea-1.md`.
- Cuestionario del tema 1 (60 %): diez preguntas de opción múltiple y verdadero/falso.

## Errores frecuentes de otros años

- Pensar que una variable "no puede cambiar" una vez asignada (confunden variable con
  constante).
- Creer que `float` es "texto con decimales" porque lo ven escrito entre comillas en algún
  ejemplo de internet.
- Arreglar `"3" + 3` "quitando las comillas" en vez de convertir el dato que llega como texto.
